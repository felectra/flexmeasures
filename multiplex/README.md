# Multiplex «Атмосфера» — EMS-арбітраж на FlexMeasures

Робоча гілка `multiplex/atmosfera-ems`. Комерційне продовження лабораторного пілота
(rock3a) — та сама EMS (FlexMeasures), але ціль інша.

## Мета (за словами замовника)

**Фінансова економія**, не резерв. У ТРЦ «Атмосфера» генератори на блекаут вже є, тож backup
не драйвер. Головні важелі:

1. **Тарифний арбітраж батареї** — заряджати, коли енергія дешева (нічна зона / низька ціна
   РДН, закупівля через постачальника, напр. ТОВ ЯСНО — дочка ДТЕК), і віддавати собі в дорогі
   (пікові) години. Різниця цін × енергія за цикл = економія.
2. **Агрегація 20+ кінотеатрів** — сумарний профіль дає кращу тарифну/ринкову позицію та
   гуртову переговорну силу з постачальником.
3. (Вторинні, за наявності) зниження плати за потужність; демонд-респонс / балансуючий ринок —
   лише якщо реально доступні на масштабі кінотеатру.

## Дані

- **АСКОЕ Мультіплекса** (Миколаїв, ТРЦ Сіті Центр) — **30-хв профілі навантаження**; надає
  власник. Це вхід №1 для моделі.
- Далі — профілі 20+ кінотеатрів для агрегації.
- Ринкові дані (зонні тарифи, РДН) — з дослідження ринку України (в роботі).

## Підхід

- FlexMeasures `StorageScheduler` із **ціновим/зонним flex-context** (ToU або РДН-ціни) →
  арбітражний розклад заряду/розряду на реальному профілі.
- Квантифікація: **грн/добу, грн/рік, окупність** батареї; чутливість до ємності/спреду/циклів.
- Чесність: розрізняти backcast із ідеальним передбаченням (верхня межа) і реалістичний
  результат із прогнозом; реальні тарифи, не химерні сценарії.

## Результати (deliverables)

1. **Фінансова модель арбітражу** на 30-хв даних Мультіплекса.
2. **Презентація для Мультіплекса** про нашу EMS (FlexMeasures) — фінансовий фокус.
3. **Локальна практична версія для Сергія** (АСКОЕ-friendly, BMS-новачок; без облікового
   Claude → локальний html).
